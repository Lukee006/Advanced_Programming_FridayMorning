# CampusWheels Vehicle-Rental Desk

## How to Run

Open a terminal in the `Assignment_02` folder and run:

```bash
python main.py
```

The program demonstrates vehicles, renters, renting and returning vehicles, error handling, inheritance, and polymorphism.

## Files

* `rental.py` - Contains the Vehicle, Renter, ElectricCar, and Motorbike classes.
* `main.py` - Demonstrates that the classes work.
* `README.md` - Contains instructions for running the program and the AI-use note.

## AI Use Note

I used AI to help explain Object-Oriented Programming concepts such as classes, inheritance, properties, getters, setters, and polymorphism. I wrote and tested the code myself.
